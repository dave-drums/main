# HELP standalone site

To move this independent site to its own domain, copy this folder's contents into the new site's document root:

- `index.html`
- `styles.css`
- `script.js`
- `help-logo.png`
- `favicon.png`
- `bg.mp4`
- `help-audio.mp3`

All local URLs are relative to this folder. No Dave Drums stylesheet, script, font, package or build step is required. Keep the media files with the page. The Instagram link is the only external destination.

The page retains `noindex` from its temporary coming-soon setup. Review that when launching the new domain.
