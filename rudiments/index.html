How to use the Rudiment Trainer

  1. Choose one of the 40 rudiments and a lead hand. R/L beneath the notes shows which hand plays each stroke.
  2. Set 40–240 BPM with the slider, number field or +/− buttons. Use Tap tempo to find a pulse.
  3. Press Start to loop the pattern and follow the highlighted stroke. Stop ends playback. Space also starts or stops when focus is outside a control.
  4. The metronome clicks quarter notes. For Speed trainer, stop playback, enable it and set the starting/target BPM, increase and repetitions. One repetition is the complete pattern; playback builds to the target and holds there.
  5. Use Full screen where supported; Escape exits. Leaving the tab pauses playback. Press Start when you return.

Reading notation: > marks an accent; small notes are quieter grace strokes before the main stroke. A dot adds half a note’s value. 3 and 6 mark tuplets. Z means uncounted buzz rebounds; its eighth notes guide hand changes. Open rolls show individual strokes.

Start comfortably, balance both hands and increase speed only when the pattern stays relaxed and even. Patterns follow the PAS rudiments and Vic Firth reference figures.
